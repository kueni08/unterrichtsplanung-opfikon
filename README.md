# Unterrichtsplanung Opfikon

Digitale Wochenplanung für altersdurchmischte Klassen und Teamteaching.

## Testzugänge

- **Nici · Lehrperson** – persönliche Ansicht
- **Koordination · Gesamtansicht** – alle Gruppen und Adminbereich
- Testpasswort: `Opfikon2026`

Die Testversion verwendet ausschliesslich anonymisierte Kinderkürzel (z. B. A01, B03). Der Login ist eine reine Demo und keine sichere Benutzerverwaltung. Für produktive Schuldaten sind serverseitige Authentifizierung, Rollenrechte und eine geschützte Datenbank erforderlich.

## Start

```bash
npm install
npm run dev
```

Die Anwendung basiert auf Next/Vinext und ist für eine Veröffentlichung über Cloudflare Sites vorbereitet.
